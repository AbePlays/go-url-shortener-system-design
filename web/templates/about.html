About this little project

This is a URL shortener built in Go — not just to work, but to practice real system design thinking.

What’s under the hood

  • PostgreSQL as the source of truth
  • Redis for speedy reads
  • Primary + read replica setup
  • Honest trade-offs around consistency and lag

Tech stack

  • Go
  • PostgreSQL + Redis
  • Docker Compose
  • Plain HTML & CSS (no JavaScript)

Made for learning system design the hands-on way.
